# Meridian Museum

A React single-page application for browsing museum exhibitions, guided tours, and
workshops, then assembling a timed-entry visit pass.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```

Bookings and schedule availability are simulated in the browser. The visit pass is
stored in local storage; no payment or reservation is sent to a museum service.
